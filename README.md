## Flagship engineering platform

### Manufacturing Process Excellence Toolkit

An integrated manufacturing engineering platform connecting **process capability, PFMEA, SPC, OEE, Gauge R&R, yield, process data, engineering-lessons retrieval, and evidence-grounded decision support**.

It is designed around the engineering workflow:

**Measurement system → process stability → capability → risk → losses → corrective action → verification**

- **V1 Classic:** Cp/Cpk, PFMEA, OEE, Gauge R&R, SPC, and process-data analysis
- **V1 Interactive:** user-selected capability data, scenario analysis, and downloadable reporting
- **V2 Manufacturing Intelligence:** FPY/RTY, production records, BM25 lessons retrieval, engineering briefs, and integrated reporting
