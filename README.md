## Emerging R&D: AI-assisted manufacturing diagnostics

**In development — not yet a production service.** An engineering-focused assistant combining tested deterministic calculation tools with language-model interpretation, guided data intake and human engineering review.

- **Step 1:** Analyze production demand, shift capacity, bottleneck cycle and OEE with auditable formulas.
- **Step 2:** Summarize likely constraints and suggest what measurements to collect next.
- **Step 3:** Prepare a draft manufacturing diagnostic for engineer approval.
- **Architecture:** Python calculation engine + optional OpenAI Agents SDK / Hugging Face model-backed explanations. No credentials stored in public code.
- **FODGuard roadmap:** Explore AI-assisted, evidence-grounded root-cause hypothesis generation for human engineering review. This is planned development, not a validated current feature.

**Commercial goal:** Pilot a scoped *Manufacturing Capacity & Labor Optimization Assessment* for manufacturers that need a defensible process improvement plan. [Discuss a pilot](mailto:fitsum@fitexindustrial.com?subject=FitEx%20Manufacturing%20Diagnostic%20Inquiry).
